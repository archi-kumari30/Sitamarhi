# Sitamarhi – Divine Temples & Rituals

A simple static website showcasing famous temples, religious places, and Chhath Puja rituals associated with Sitamarhi, Bihar.

## 🌐 Live Website

[Visit the Sitamarhi Website](https://archi-kumari30.github.io/Sitamarhi/)

## 📖 About the Project

The Sitamarhi website is a frontend project created to provide information about famous temples and religious traditions of Sitamarhi.

The website focuses on presenting the content in a simple, attractive, and easy-to-navigate format using HTML and CSS.

## ✨ Features

* 🏠 Home page with a welcome section
* 🛕 Famous temples section
* 🙏 Chhath Puja rituals and steps
* 💰 Donation page with a donation form UI
* 🖼️ Images of temples and religious places
* 📱 Simple and clean webpage design
* 🔗 Navigation between different pages
* 🌐 Hosted using GitHub Pages

## 📄 Website Pages

### Home

Introduces visitors to the website and provides navigation to the main sections.

### Temples

Displays information and images of famous temples and religious places in Sitamarhi.

### Rituals

Provides information about Chhath Puja rituals and different stages of the festival.

### Donations

Contains a donation form interface with fields for name, email, donation amount, payment method, and an optional message.
